Byte-sequence test vectors for the Thermaestro gateway protocol and the Nibe bus
framing, copied from [Thermaestro](https://github.com/fnordpojk/thermaestro)'s
`testvectors/`. They are MIT-licensed (see `LICENSE`) so they can live here; the
Python implementation is tested against the same files, so the two stay identical.
Update them by copying the files again, not by editing them here.
